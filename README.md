# NoServerPicViewer (本地极速图片浏览器)

> **零服务端、零依赖、纯单文件架构的现代本地图片浏览器。**
> 基于原生 HTML5 / ES2022 / CSS3 构建，利用现代 Web API（FileSystem Access API、createImageBitmap 硬件加速解码、IndexedDB）实现媲美本地原生相册的极速流畅体验。

🔗 **在线免下载直接使用**：[https://tianquandiwen.github.io/NoServerPicViewer/](https://tianquandiwen.github.io/NoServerPicViewer/)  
*(无需下载任何文件或安装依赖，在 Chrome / Edge 中打开链接即可在本地沙箱中安全浏览本地照片)*

---

## ✨ 核心亮点

- 🌐 **在线即用，无需下载**：托管于 GitHub Pages，随时随地在浏览器中直接打开即可使用，零安装、零配置。
- 🚀 **纯单文件，开箱即用**：全工程仅一个 `index.html`，即便离线下载到本地，双击文件即可直接在现代浏览器中极速运行。
- 🛡️ **100% 数据私密与本地离线**：所有文件读取、缩略图压缩、元数据提取与持久化均在本地浏览器沙箱中完成，**绝不发起任何网络上传，断网亦能完整使用**。
- ⚡ **数万级大图虚拟滚动 (Virtual Grid)**：仅按需挂载视口可见卡片与有限缓冲区，无论目录下有数百张还是数万张图片，DOM 节点数恒定，滚动帧率稳居 60fps。
- 🖼️ **单步硬件抗锯齿位图缩放管线**：大图在后台线程通过 `createImageBitmap` 完成硬件解码，主线程并发队列控制（默认 3 并发）结合 Canvas 2D 导出轻量 JPEG 缩略图，并由 `finally` 严格兜底显存句柄释放，彻底告别内存爆炸与掉帧卡顿。
- 💾 **惰性原图加载与安全 LRU 缓存**：大图缩略图由 1000 容量的 LRU 缓存统一管理，原图仅在查看灯箱或小图时纯惰性创建；原图 Object URL 纳入全局安全集合，绝不被缩略图 LRU 淘汰所误杀。
- 🌲 **无限级目录树与流式增量索引**：支持深层子文件夹树状导航与状态记忆；流式扫描中实时增量呈现，配合 $O(1)$ 指标统计与滚动位置保持，大相册扫描丝滑不卡顿。
- 🔍 **沉浸式平移缩放灯箱 (Lightbox)**：全屏预览、鼠标滚轮缩放、任意拖拽平移、键盘快捷操作、移动端双指 Pinch 捏合手势、滑动翻页与一键原图复制到剪贴板。
- 🌓 **Apple 极简美学设计**：自适应浅色与深色主题（`prefers-color-scheme`），优雅的毛玻璃控制栏、卡片悬浮立体阴影与移动端抽屉动画。

## 🚀 运行与使用方式

### 方式 1：在线直接使用（首选推荐，免下载）
无需克隆仓库或下载文件，直接在 Chromium 内核浏览器中访问：  
👉 **[https://tianquandiwen.github.io/NoServerPicViewer/](https://tianquandiwen.github.io/NoServerPicViewer/)**  
即可随时随地在安全的本地浏览器沙箱中浏览您的本地相册。

### 方式 2：本地双击打开（离线零依赖）
只需下载仓库中的单个文件 [`index.html`](index.html)，在文件管理器中**直接双击打开**（或右键选择使用 Chrome / Edge 打开），无需安装任何 Node.js、Python 等环境，开箱即用。

### 方式 3：简易本地静态服务（可选）
如果您需要在内网设备共享或开发调试，也可使用简易本地服务运行：
```bash

python -m http.server 8000

# 或使用 Node.js 启动
npx serve .
```

## 💻 浏览器兼容性要求

- **推荐浏览器**：Google Chrome 86+、Microsoft Edge 86+ 或其他基于 Chromium 内核的现代桌面/移动端浏览器。
- **核心 API 依赖**：浏览器需支持 [FileSystem Access API](https://developer.mozilla.org/zh-CN/docs/Web/API/File_System_API)（即 `window.showDirectoryPicker`）以及 `createImageBitmap`。

## 📖 操作指引

1. **选择相册**：点击顶部导航栏的 **“📂 选择文件夹”** 按钮，在弹出的系统选择框中选中相册目录，并允许只读授权。
2. **多级目录树**：左侧展示无限级子文件夹目录树，支持点击箭头展开/折叠，点击目录快速切换当前可见范围。
3. **断点记忆**：浏览器通过 IndexedDB 持久化记录目录句柄。下次重新进入页面时，浏览器会自动检测并弹出恢复上次会话的提示，一键无缝还原。

## ⌨️ 快捷键与操作指南

### 基础交互
| 操作场景 | 交互方式 | 说明 |
| :--- | :--- | :--- |
| **切换目录** | 单击左侧目录树节点 | 切换当前展示文件夹（支持展开/折叠箭头） |
| **快速检索** | 顶部搜索框输入文字 | 实时防抖检索文件名（包含匹配） |
| **筛选与排序** | 排序下拉菜单 / 日期输入框 | 支持按时间、名称、大小正反序及日期区间过滤 |
| **打开大图** | 单击任意卡片 | 唤出沉浸式大图灯箱 |

### 灯箱预览快捷键
| 键盘快捷键 | 对应操作 |
| :--- | :--- |
| <kbd>Esc</kbd> | 退出全屏 / 关闭灯箱预览 |

| <kbd>+</kbd> / <kbd>=</kbd> | 放大图片（步进 25%，最高 500%） |

| <kbd>0</kbd> | 重置缩放倍率与平移偏移量（复位 100%） |
| <kbd>F</kbd> | 切换全屏模式 / 退出全屏 |

### 移动端触控手势
- **双指捏合 / 张开 (Pinch-to-zoom)**：自由放大、缩小图片。
- **单指拖拽**：在放大（`scale > 1`）状态下任意平移拖拽查看细节。
- **单指轻扫**：在未放大（`scale = 1`）状态下，左右滑动手势快速切换上一张 / 下一张。

## 🛠️ 调优配置项 (`CONFIG`)

若您需要根据特定硬件性能或展示偏好调整参数，可直接在 [`index.html`](index.html) 源码前部的 `CONFIG` 对象中进行微调：

```javascript
const CONFIG = {
    ROW_OVERSCAN: 6,                      // 虚拟滚动视口上下预加载的缓冲区行数
    SCROLL_STOP_DELAY: 50,                // 滚动停止判断防抖时间 (ms)
    SWIPE_THRESHOLD: 50,                  // 移动端手势滑动切换图片的灵敏度阈值 (px)
    SEARCH_DEBOUNCE: 300,                 // 搜索输入框实时防抖延时 (ms)
    GRID_MIN_COL_WIDTH: 180,              // 卡片自适应网格最小列宽 (px)
    MAX_CONCURRENT_THUMBNAIL_TASKS: 3,    // 大图缩略图后台压缩最大并发槽位数
    THUMBNAIL_TASK_TIMEOUT: 12000,        // 单张大图硬件解码与压缩超时熔断时间 (ms)
    THUMBNAIL_SIZE_THRESHOLD: 500 * 1024, // 触发缩略图压缩的文件大小阈值 (默认 500KB)
    THUMBNAIL_MAX_WIDTH: 400,             // 生成缩略图的最大目标宽度 (px)
    THUMBNAIL_MAX_HEIGHT: 300,            // 生成缩略图的最大目标高度 (px)
    THUMBNAIL_QUALITY: 0.8,               // 缩略图 JPEG 编码质量 (0.1 ~ 1.0)
    LRU_CACHE_MAX_SIZE: 1000,             // 缩略图 Blob URL 最大缓存容量
    IMAGE_LOAD_TIMEOUT: 15000,            // 网格卡片图片加载超时阈值 (ms)
    LIGHTBOX_LOAD_TIMEOUT: 10000,         // 灯箱原图读取超时阈值 (ms)
    LOG_LEVEL: 'warn',                    // 日志输出级别: 'debug' | 'info' | 'warn' | 'error' | 'none'
};
```

## 📄 支持格式

支持现代浏览器所兼容的所有常见光栅图与矢量图格式：
- `JPG` / `JPEG` / `JFIF`
- `PNG`

- `BMP`

- `TIFF` / `TIF`（需浏览器原生解码支持）
- `HEIC` / `HEIF`（需系统与浏览器具备硬件解码扩展）

## 🔒 隐私与安全性申明

1. **零外部网络通信**：本应用不包含任何第三方 CDN 脚本、追踪代码、统计分析或远程资源，断网状态下功能 100% 完整运行。
2. **只读访问安全**：通过 FileSystem Access API 请求的句柄均为纯只读模式（`mode: 'read'`），不会对您的本地原始文件进行任何修改、覆盖或删除。
3. **内存即刻回收**：切换目录或关闭页面时，所有由应用创建的 Object URL 及位图资源句柄均会彻底显式释放并交由 V8 引擎 GC。
